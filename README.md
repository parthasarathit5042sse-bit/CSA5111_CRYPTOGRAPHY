# CSA5111 – Cryptography and Network Security

A coursework repository for **CSA5111 (Cryptography and Network Security)**. It contains C implementations of classical encryption algorithms, decryption techniques, cryptanalysis exercises, practical programs, assessments, and capstone project work.

## Repository Structure

```
CSA5111_CRYPTOGRAPHY/
├── ASSESSMENTS/      # Graded assessment programs and solutions
├── CAPSTONE/         # Capstone project work
├── CLASS ACTIVITY/   # In-class exercises and activities
└── PRACTICALS/       # Lab / practical programs
```

| Folder | Description |
| --- | --- |
| `ASSESSMENTS` | Programs and solutions submitted for course assessments |
| `CAPSTONE` | Capstone project combining the concepts studied in the course |
| `CLASS ACTIVITY` | Exercises worked on during classes |
| `PRACTICALS` | Hands-on implementations of encryption, decryption and cryptanalysis techniques |

## Topics Covered

- Classical encryption and decryption techniques (substitution and transposition ciphers)
- Cryptanalysis exercises (breaking ciphers)
- Core network security concepts
- Practical implementation in C

## Requirements

- A C compiler such as **GCC** (or any IDE like Code::Blocks / Dev-C++)

## How to Compile and Run

```bash
# Clone the repository
git clone https://github.com/parthasarathit5042sse-bit/CSA5111_CRYPTOGRAPHY.git

# Compile a program (replace file name with the program you want)
```

## Tech Stack

- **Language:** C
- **Domain:** Cryptography, Cybersecurity, Network Security
